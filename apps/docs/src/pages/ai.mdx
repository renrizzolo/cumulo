# Working with AI

#### How to build with Cumulo using AI coding assistants (Claude Code, Cursor, Copilot, Codex, Antigravity, etc.).

Cumulo is designed so coding assistants can compose accessible, themeable UI without hallucinating styles.

When an AI assistant builds user interfaces, it typically defaults to generic HTML tags (`<div>`), arbitrary utility classes (Tailwind), or monolithic inputs.

Providing your AI assistant with clear rules on Cumulo's components and design tokens ensures it produces clean, accessible, on-system code on the first try.

## Copy-Paste Consumer Prompt

Add this snippet to your project's `.cursorrules`, `AGENTS.md`, or custom instructions:

```text
You are building user interfaces with Cumulo UI (@cumulo/core and @cumulo/css).

RULES:
1. Layout: Never use raw <div> for layout or flexbox. Use <HStack>, <VStack>, <Stack>, or <Container>.
2. Forms: Always use compound <Field.Root>, <Field.Label>, <Field.Input>, <Field.Error> slots.
3. Styling: Never use Tailwind classes or arbitrary hex values. Use @cumulo/css style() or recipe() with tokens from vars.* (@cumulo/core). Always look for available layout primitives before reaching for custom styles.
4. Theming: Use data-theme for creating branded themes in css ([data-theme='<theme-name>'] { --color-primary-base: '...' }).

SELF-CHECK:
Before completing your response, re-read your generated code and replace any unstyled <div> containers, raw hex colors, or inline styles with Cumulo primitives and vars.* tokens, unless the user explicitly requests otherwise.
```
