# Cumulo UI

#### _Cumulo_ (cù·mu·lo), Italian (n.) - A heap, pile, or accumulation of things.

Cumulo is a collection of UI components and related artifacts - a React 19 design system and lightweight CSS engine with no runtime dependencies.

## Features

- **No runtime dependencies**: Built on React 19 and modern CSS.
- **Type-safe CSS**: `@cumulo/css` is a ~2kB engine with theme contracts, scoped style rules, keyframes, and deterministic hashing.
- **Dynamic surfaces**: Nested interactive elements deepen automatically through `--surface-bg-next`.
- **OKLCH color seeding**: Full color palettes are computed in CSS from a few seed colors, using `light-dark()`.

## Install

```bash
pnpm add @cumulo/css @cumulo/core
```
