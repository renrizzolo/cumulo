# Cumulo UI

> _Cumulo_ (cù·mu·lo), Italian (n.) — a heap, pile, or accumulation of things.

Cumulo is a collection of UI components and related tooling: a React 19 design system and a lightweight CSS engine with zero runtime dependencies.

## Features

- **Zero runtime dependencies**: Built on React 19 and modern CSS.
- **Type-safe CSS**: `@cumulo/css` is a ~2kB engine with theme contracts, scoped style rules, keyframes, and deterministic hashing.
- **Dynamic surfaces**: Nested interactive elements deepen automatically through `--surface-bg-next`.
- **OKLCH color seeding**: Full color palettes are computed in CSS from seed colors using `light-dark()`.

## Installation

```txt
pnpm add @cumulo/css @cumulo/core
```
