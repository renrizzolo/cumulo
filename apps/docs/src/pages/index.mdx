### Core features

<List.Root as="dl">
  <List.Item icon="🌐" term="Platform-first components">

  </List.Item>

    `light-dark()`.

### Installation

Install the core component library and CSS framework:

```bash
pnpm add @cumulo/core @cumulo/css
```

<BundlerAlert />

Install the universal bundler plugin (or <code>@cumulo/parcel-transformer</code> if using Parcel):

```bash
pnpm add -D @cumulo/unplugin
```

Configure the plugin in your bundler (e.g. Vite):

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import { cumulo } from '@cumulo/unplugin/vite';

export default defineConfig({
  plugins: [react(), cumulo()],
});
```

See [Bundler Setup](/bundlers) for Next.js, Webpack, Rollup, esbuild, and Parcel configurations.

### Load theme styles

`@cumulo/core` ships with a prebuilt stylesheet at `@cumulo/core/theme.css`. It provides two layers:

- **Reset styles** (`@layer reset`): Box-sizing, margin resets, baseline body styling, and form element font inheritance.
- **Theme tokens** (`@layer base`): CSS variables for colors, surfaces, spacing, border radii, and typography scales.

You have two options to load theme styles:

#### Option 1: Import the prebuilt stylesheet

Import `@cumulo/core/theme.css` in your application root file (such as `main.tsx` or `App.tsx`):

```ts
// src/main.tsx
import '@cumulo/core/theme.css';
```

Or import it in your global stylesheet:

```css
/* src/styles.css */
@import '@cumulo/core/theme.css';
```

#### Option 2: Provide a custom stylesheet

If you prefer to manage your own design tokens and CSS reset, create a stylesheet defining the required CSS variables.

Define the token variables on `:root` or scoped `[data-theme='...']` attributes. By providing your own stylesheet, you may skip importing `@cumulo/core/theme.css`.

In most cases you will want to import `@cumulo/core/theme.css` and override select CSS variables.

See the [Tokens and theming](/tokens) reference for the complete list of CSS variables.
