# Cumulo UI

A modern, dependency-free React 19 component library and lightweight CSS engine inspired by StyleX and Vanilla Extract. _Cumulo_ (Italian for _pile_ or _hoard_) represents an accumulation of composable primitives and design tokens.

## Architecture Highlights

- **100% Dependency-Free**: Zero third-party runtime dependencies. Built purely on React 19 primitives and modern CSS capabilities.
- **@cumulo/css Engine**: A fast, ~2kB type-safe CSS framework with theme contracts, scoped style rules, keyframes, and deterministic hashing.
- **Dynamic Surface System**: Contextual depth propagation where nested interactive elements automatically deepen via `--surface-bg-next`.
- **Mathematical OKLCH Color Seeding**: Live color gamut computation directly in CSS using trigonometric chroma curves and `light-dark()`.
- **React Server Components**: Statically pre-rendered pages built with Parcel RSC router and selective client hydration.

## Quick Installation

```bash
# Install @cumulo/css and @cumulo/core
pnpm add @cumulo/css @cumulo/core
```
