# Cumulo UI

A modern, dependency-free React component library and lightweight CSS engine inspired by StyleX and Vanilla Extract.

## Architecture Highlights

- **100% Dependency-Free**: Zero runtime third-party dependencies. Built purely on React 19 primitives and modern CSS.
- **@cumulo/css Engine**: A fast, ~2kB type-safe CSS framework with theme contracts, scoped style rules, keyframes, and deterministic hashing.
- **React Server Components**: Statically pre-rendered pages built with Parcel RSC router and client hydration.
