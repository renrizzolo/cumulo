# Tokens and theming

Cumulo's token system is built on CSS custom properties. Theming can be easily achieved by overriding these properties in your own stylesheets. See the [interactive theme builder](/theme-builder) to quickly create and test custom themes.

```ts
import { vars } from '@cumulo/core';
```

## Surfaces

Surfaces define contextual custom properties. Nested interactive elements, such as inputs and buttons are surface-aware.

## Color seeds

Color palettes are built from the following CSS custom properties: `--color-grey-base`, `--color-primary-base`, `--color-success-base`, `--color-warning-base`, `--color-error-base`, and `--color-info-base`. Cumulo's theme stylesheet computes each full 50–900 palette using relative color syntax, trigonometric chroma curves (`sin(t * pi)`), and `light-dark()`.
