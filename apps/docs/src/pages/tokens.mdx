# @cumulo/core Tokens & CSS-First Theming

Dynamic surfaces, mathematical OKLCH color seeding, and bleeding-edge CSS capabilities.

## Dynamic Surface System

Surfaces define contextual CSS custom properties so that nested interactive elements (inputs, cards, hover states) automatically deepen and darken relative to their container hierarchy.

<TokenTable category="surface" />

## Mathematical OKLCH Color Seeding

Themes are seeded from base variables (`--color-primary-base`, `--color-success-base`, etc.) and dynamically calculate full 50–900 stepped palettes live in CSS using relative color syntax, trigonometric chroma curves (`sin(t * pi)`), and `light-dark()`.
