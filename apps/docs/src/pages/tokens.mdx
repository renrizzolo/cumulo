## Built-in Themes

Cumulo Core ships with three out-of-the-box themes:

- **`lightTheme`**: Crisp, high-contrast light mode for clean readability.
- **`darkTheme`**: Deep slate dark mode with subdued borders and glowing accents.
- **`cloudTheme`**: Signature translucent mist palette with soft glassmorphism.

```tsx
import { lightTheme, darkTheme, cloudTheme } from "@cumulo/core";
```
