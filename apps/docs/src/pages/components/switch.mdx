# Switch

An accessible toggle switch with a sliding thumb animation, and Field integration.

```tsx
import { Switch } from '@cumulo/core';
```

### Examples

<ComponentPreview title="Switch Toggle">
  <VStack gap="md">
    <FieldRoot>
      <HStack gap="sm" align="center">
        <FieldSwitch />
        <FieldLabel>Enable Feature</FieldLabel>
      </HStack>
    </FieldRoot>
    <FieldRoot>
      <HStack gap="sm" align="center">
        <FieldSwitch defaultChecked />
        <FieldLabel>Active by Default</FieldLabel>
      </HStack>
    </FieldRoot>
  </VStack>
</ComponentPreview>

## States and intents

Switches support checked, unchecked, error, and disabled states. Accessibility attributes are wired automatically.

<ComponentPreview title="Switch states and intents">
  <VStack gap="md">
    <FieldRoot>
      <HStack gap="sm" align="center">
        <FieldSwitch />
        <FieldLabel>Default (Unchecked)</FieldLabel>
      </HStack>
    </FieldRoot>
    <FieldRoot>
      <HStack gap="sm" align="center">
        <FieldSwitch defaultChecked />
        <FieldLabel>Checked</FieldLabel>
      </HStack>
    </FieldRoot>
    <FieldRoot isInvalid>
      <HStack gap="sm" align="center">
        <FieldSwitch />
        <FieldLabel>Error State</FieldLabel>
      </HStack>
      <FieldError>This setting requires immediate review.</FieldError>
    </FieldRoot>
    <FieldRoot>
      <HStack gap="sm" align="center">
        <FieldSwitch disabled />
        <FieldLabel>Disabled (Unchecked)</FieldLabel>
      </HStack>
    </FieldRoot>
    <FieldRoot>
      <HStack gap="sm" align="center">
        <FieldSwitch disabled defaultChecked />
        <FieldLabel>Disabled (Checked)</FieldLabel>
      </HStack>
    </FieldRoot>
  </VStack>
</ComponentPreview>

## Field integration

When used inside a `FieldRoot`, switches automatically synchronize IDs, descriptions, accessibility attributes, and error validation states.
