# Switch

A smooth, accessible toggle switch control with sliding thumb animations.

```tsx
import { Switch } from '@cumulo/core';
```

## Features

- **Semantic Role**: Employs `role="switch"` with dynamic `aria-checked`.
- **Smooth Animation**: Pure CSS transition on thumb transform and track background.
- **T-Shirt Sizing**: `sm`, `md`, `lg`.
- **Keyboard Support**: Space bar and Enter toggling out of the box.
