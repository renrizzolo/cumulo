# AppFrame

The top-level application shell. `AppFrame` lays out a sidebar beside `AppFrame.Main` in a row, and `AppFrame.Main` stacks a header above a scrollable content area.

```tsx
import { AppFrame, Sidebar, Panel } from '@cumulo/core';
```

`AppFrame` only handles layout. For docked, inset or floating styles, set `variant` on [`Sidebar`](/components/sidebar.html).

### Anatomy

```tsx
<AppFrame>
  <Sidebar>{/* navigation */}</Sidebar>
  <AppFrame.Main>
    <Panel as="header" divider="bottom">
      {/* header */}
    </Panel>
    <Panel scrollbar="thin">{/* page content */}</Panel>
  </AppFrame.Main>
</AppFrame>
```

### Height

The `height` prop sets how the frame fills vertical space.

<Table variant="bordered">
  <Table.Header>
    <Table.Row>
      <Table.Head>Value</Table.Head>
      <Table.Head>Behaviour</Table.Head>
    </Table.Row>
  </Table.Header>
  <Table.Body>
    <Table.Row>
      <Table.Cell>
        <Code>screen</Code> (default)
      </Table.Cell>
      <Table.Cell>
        Locks the frame to the viewport (<Code>100dvh</Code>). The sidebar and main area scroll on
        their own.
      </Table.Cell>
    </Table.Row>
    <Table.Row>
      <Table.Cell>
        <Code>full</Code>
      </Table.Cell>
      <Table.Cell>
        Fills the parent's height (<Code>100%</Code>). Use this to embed the frame in a sized
        container.
      </Table.Cell>
    </Table.Row>
    <Table.Row>
      <Table.Cell>
        <Code>auto</Code>
      </Table.Cell>
      <Table.Cell>
        Grows with its content (at least <Code>100dvh</Code>), so the whole page scrolls.
      </Table.Cell>
    </Table.Row>
  </Table.Body>
</Table>

### Accessibility

`AppFrame.Main` renders a `<main>` landmark by default. If a descendant already renders `<main>`, pass `as="div"` so the page has only one.
