# Button

Buttons trigger actions with a single click or tap.

```tsx
import { Button } from '@cumulo/core';
```

### Examples

<ComponentPreview>
  <HStack gap="sm" wrap="wrap" align="center">
    <Button variant="primary">Primary</Button>
    <Button variant="secondary">Secondary</Button>
    <Button variant="outline" intent="success">
      Outline success
    </Button>
    <Button variant="ghost" intent="error">
      Ghost error
    </Button>
    <Button size="sm" variant="primary" shape="round">
      Round small
    </Button>
  </HStack>
</ComponentPreview>

## Variants

Buttons support four variants: `primary`, `secondary`, `outline`, and `ghost`.

<ComponentPreview>
  <HStack gap="sm" wrap="wrap">
    <Button variant="primary">Primary</Button>
    <Button variant="secondary">Secondary</Button>
    <Button variant="outline">Outline</Button>
    <Button variant="ghost">Ghost</Button>
  </HStack>
</ComponentPreview>

## Intents

Use an intent to change the color: `primary`, `success`, `warning`, `error`, or `info`.

<ComponentPreview>
  <HStack gap="sm" wrap="wrap">
    <Button variant="primary" intent="primary">
      Primary
    </Button>
    <Button variant="primary" intent="success">
      Success
    </Button>
    <Button variant="primary" intent="warning">
      Warning
    </Button>
    <Button variant="primary" intent="error">
      Error
    </Button>
    <Button variant="primary" intent="info">
      Info
    </Button>
  </HStack>
</ComponentPreview>

## Sizes and shapes

Buttons come in `xs`, `sm`, `md`, `lg`, and `xl` sizes, with `default` and `round` shapes.

<ComponentPreview>
  <HStack gap="sm" align="center" wrap="wrap">
    <Button size="xs">Extra small</Button>
    <Button size="sm">Small</Button>
    <Button size="md">Medium</Button>
    <Button size="lg">Large</Button>
    <Button size="xl">Extra large</Button>
    <Button shape="round" variant="secondary">
      Round
    </Button>
    <Button disabled variant="primary">
      Disabled
    </Button>
  </HStack>
</ComponentPreview>
