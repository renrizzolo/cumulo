# Button

Buttons allow users to take actions, make choices, and trigger state changes with a single tap or click.

```tsx
import { Button } from '@cumulo/core';
```

## Visual Variants

Cumulo buttons support four core visual variants: `primary`, `secondary`, `outline`, and `ghost`.

<ComponentPreview>
  <HStack gap="sm" wrap="wrap">
    <Button variant="primary">Primary</Button>
    <Button variant="secondary">Secondary</Button>
    <Button variant="outline">Outline</Button>
    <Button variant="ghost">Ghost</Button>
  </HStack>
</ComponentPreview>

## Semantic Intents

Buttons automatically adapt their styling according to system intents (`primary`, `success`, `warning`, `error`, `info`).

## Sizes & Shapes

Buttons offer `small`, `base`, and `large` sizes, with `default` and `round` shapes.
