# Select

Customizable `<select>` dropdown control (`appearance: base-select`) with styled `::picker(select)` popup, options, checkmarks, option groups, variants, intents, sizing scales, and compound `Field.Select` integration.

```tsx
import { Select, Field } from '@cumulo/core';
```

## Variants and intents

Supports `outline`, `filled`, and `ghost` variants along with `default`, `error`, and `success` intents.

    <VStack gap="md">

        <option value="outline">Outline Variant (Default)</option>
        <option value="other">Other Option</option>
      </Select>
      <Select variant="filled" defaultValue="filled" aria-label="Filled select">
        <option value="filled">Filled Variant</option>
        <option value="other">Other Option</option>
      </Select>
      <Select variant="ghost" defaultValue="ghost" aria-label="Ghost select">
