# Input

Text input field with variant, intent, sizing (`2xs` through `lg`), and `leading` / `trailing` adornment slots.

```tsx
import { Input } from '@cumulo/core';
```

## Adornments

Inputs support `leading` and `trailing` props to render icons, prefix/suffix text, keyboard shortcut badges (`<Kbd>`), or interactive action controls.

- **`leading`**: Adornment rendered before the input text (e.g. search icons, currency symbols, protocol prefixes).
- **`trailing`**: Adornment rendered after the input text (e.g. keyboard shortcuts, clear triggers, unit labels).

When adornments are provided, `Input` renders a wrapper that manages flex alignment, focus-within states (`:focus-within`), and transitions adornment icons between subtle and foreground colors on focus. All native input props and the `ref` are forwarded directly to the underlying `<input>`.
