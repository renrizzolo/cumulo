# Input

Text input field with variant, intent, sizing (`2xs` through `lg`), and `leading` / `trailing` adornment slots.

```tsx
import { Input } from '@cumulo/core';
```

### Examples

<ComponentPreview title="Inputs & Adornments">
  <Container size="sm" padding="none">
    <VStack gap="md">
      <Input placeholder="Default Input" />
      <Input
        leading={
          <Text size="xs" color="muted">
            https://
          </Text>
        }
        trailing={<Kbd size="sm">⌘K</Kbd>}
        placeholder="cumulo.dev"
      />
      <Input intent="success" defaultValue="Valid input value" />
      <Input intent="error" defaultValue="Invalid input value" />
    </VStack>
  </Container>
</ComponentPreview>

## Sizes

Supports `2xs`, `xs`, `sm`, `md`, and `lg` control heights matching `Button` and `Select`.

      <Input size="md" placeholder="Medium Input (36px)" />
      <Input size="lg" placeholder="Large Input (44px)" />

</ComponentPreview>
