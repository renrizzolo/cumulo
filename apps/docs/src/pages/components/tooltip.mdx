# Tooltip

A lightweight hint built on the native HTML [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API) and CSS anchor positioning.

```tsx
import { Tooltip } from '@cumulo/core';
```

### Examples
