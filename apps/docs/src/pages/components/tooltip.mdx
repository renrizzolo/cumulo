# Tooltip

A lightweight, non-modal contextual hint built on native HTML Popover and CSS Anchor Positioning. Automatically elevated to the top layer detached from all overflow and scroll constraints.

```tsx
import { Tooltip } from '@cumulo/core';
```

### Examples
