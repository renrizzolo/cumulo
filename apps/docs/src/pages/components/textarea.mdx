# Textarea

A multi-line text input field supporting resizing controls, intent states, and Field compound integration.

```tsx
import { Textarea } from '@cumulo/core';
```

## Features

- **Resize Variants**: `vertical`, `horizontal`, `both`, `none`.
- **T-Shirt Sizing**: `sm`, `md`, `lg`, `xl`, `inherit`.
- **Field Integration**: Auto-wiring for labels, helper descriptions, and error states.
