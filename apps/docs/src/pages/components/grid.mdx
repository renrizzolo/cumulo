# Grid

CSS Grid layout primitive supporting fixed column counts, responsive auto-fit (`minColumnWidth`), token spacing, and `Grid.Item` column/row spanning.

```tsx
import { Grid } from '@cumulo/core';
```

### Examples

## Responsive auto-fit grid

Use `columns="auto-fit"` with `minColumnWidth` to create responsive card grids without media query breakpoints.
