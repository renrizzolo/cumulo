# List

List provides accessible, semantic list primitives (`<ul>`, `<ol>`) with support for custom icon and emoji markers, styled bullets, and automatic numeric counters. Markers preserve clean hanging indentations across multiline text.

```tsx
import { List } from '@cumulo/core';
```
