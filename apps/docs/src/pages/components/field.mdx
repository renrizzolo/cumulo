# Field

Accessible compound form field coordinating labels, inputs, selects, textareas, checkboxes, switches, radio groups, descriptions, and error states.

```tsx
import { Field } from '@cumulo/core';
```

## Adornments

`Field.Input` supports `leading` and `trailing` adornments, allowing you to add icons, prefixes, keyboard shortcut indicators (`<Kbd>`), and action controls while maintaining full accessibility associations (`aria-labelledby` with `Field.Label`, `aria-describedby` with `Field.Description` and `Field.Error`).

<ComponentPreview title="Field with Adornments">
  <Container size="sm" padding="none">
    <VStack gap="lg">
      <Field.Root>
        <Field.Label>Search components</Field.Label>
        <Field.Input
          leading={
            <svg
              width="16"
              height="16"
              viewBox="0 0 24 24"
              fill="none"
              stroke="currentColor"
              strokeWidth="2"
              strokeLinecap="round"
              strokeLinejoin="round"
            >
              <circle cx="11" cy="11" r="8" />
              <path d="m21 21-4.3-4.3" />
            </svg>
          }
          trailing={<Kbd size="xs">⌘K</Kbd>}
          placeholder="Filter components..."
        />
        <Field.Description>
          Quickly filter components, primitives, and headless hooks.
        </Field.Description>
      </Field.Root>

      <Field.Root>

        <Field.Input

            <Text size="xs" color="muted">

          }

  </Container>
