# Field

Field coordinates form labels, inputs, error messages, and descriptions with automatic accessibility wiring (`aria-labelledby`, `aria-describedby`, `aria-invalid`, `htmlFor`).

```tsx
import { Field } from '@cumulo/core';
```

## Anatomy

```tsx
<Field.Root name="fieldName">
  <Field.Label>Label</Field.Label>
  <Field.Description>Help text</Field.Description>
  <Field.Input />
  <Field.Error>Validation message</Field.Error>
</Field.Root>
```
