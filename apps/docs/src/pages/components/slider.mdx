# Slider

An accessible range slider component for selecting numeric values along a track, with smooth thumb dragging, sizing, intent variants, and Field integration.

```tsx
import { Slider } from '@cumulo/core';
```

### Examples

<ComponentPreview title="Range Slider">
  <VStack gap="lg" style={{ width: '100%', maxWidth: '400px' }}>
    <Field.Root>
      <HStack justify="between" align="center">
        <Field.Label>Volume</Field.Label>
        <Text size="sm" color="subtle">
          50%
        </Text>
      </HStack>
      <Field.Slider defaultValue={50} min={0} max={100} />
      <Field.Description>Adjust the primary playback volume.</Field.Description>
    </Field.Root>
  </VStack>
</ComponentPreview>

## States and error integration

Sliders support default, error, and disabled states. When integrated within `<Field.Root isInvalid>`, error styling and `aria-invalid` are wired automatically.

<ComponentPreview title="Slider States">
  <VStack gap="lg" style={{ width: '100%', maxWidth: '400px' }}>
    <Field.Root>
      <Field.Label>Default Slider</Field.Label>
      <Field.Slider defaultValue={50} />
    </Field.Root>

    <Field.Root isInvalid>
      <Field.Label>Error State</Field.Label>
      <Field.Slider defaultValue={20} />
      <Field.Error>Value is below minimum threshold</Field.Error>
    </Field.Root>

    <Field.Root>
      <Field.Label>Disabled Slider</Field.Label>
      <Field.Slider disabled defaultValue={40} />
    </Field.Root>

  </VStack>
</ComponentPreview>

## Custom ranges & steps

Configure `min`, `max`, and `step` to constrain value increments.

        <Text size="sm" color="subtle">0 - 100</Text>

      <Field.Slider defaultValue={21} min={16} max={30} step={0.5} />

## States & validation

Sliders seamlessly handle `disabled` states and inherit validation errors from `Field.Root`.
