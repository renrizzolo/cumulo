# Surface

Surfaces form the foundational layering system of Cumulo. They establish contextual CSS variables (`--surface-bg`, `--surface-bg-next`, `--surface-fg`, `--surface-border`) so nested elements automatically adapt their visual depth.

```tsx
import { Surface } from '@cumulo/core';
```
