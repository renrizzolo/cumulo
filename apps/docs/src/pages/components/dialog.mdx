# Dialog

A cutting-edge modal overlay component built directly on the native HTML5 `<dialog>` element, supporting declarative light-dismiss and top-layer promotion.

```tsx
import { Dialog } from '@cumulo/core';
```

## Features

- **Native `<dialog>` Architecture**: Renders into the browser top-layer via `showModal()`.
- **Declarative Light Dismiss**: Supports `closedby="any"` with fallback backdrop click calculation.
- **Accessible ARIA Linking**: Automatically connects `aria-labelledby` to `Dialog.Title` and `aria-describedby` to `Dialog.Description`.
- **Keyboard Trapping & Escape**: Native browser focus trap and Esc key support.
- **Sizing Variants**: `sm`, `md`, `lg`, `xl`, `full`.
