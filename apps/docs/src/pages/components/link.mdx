# Link

Accessible anchor component with focus ring styling, underline offset variants (`default`, `subtle`, `plain`), and automatic `target="_blank" rel="noopener noreferrer"` security attributes when `external` is enabled.

```tsx
import { Link } from '@cumulo/core';
```
