# Popover

A lightweight non-modal floating overlay built on the native HTML Popover API with automatic top-layer elevation and light-dismiss behavior.

```tsx
import { Popover } from '@cumulo/core';
```

## Features

- **Native Popover API**: Utilizes `popover="auto"` and `popovertarget` for native browser-driven invocation and dismiss.
- **CSS Anchor Positioning**: Seamlessly anchors content to the trigger via scoped `anchor-name` and `position-anchor`.
- **Automatic Multi-Axis Fallbacks**: Leverages `position-try-fallbacks: flip-block, flip-inline, flip-block flip-inline` to automatically prevent off-screen clipping.
- **Top Layer Elevation**: Renders above all z-indexes without clipping or overflow constraints.
- **Light Dismiss**: Native outside click and escape key handling.
- **Placements**: `bottom-start`, `bottom`, `bottom-end`, `top`, `top-start`, `top-end`, `left`, `right`.
- **Sizing Variants**: `sm`, `md`, `lg`.
