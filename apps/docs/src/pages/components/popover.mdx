# Popover

A lightweight non-modal floating overlay built on the native [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API) with automatic top-layer elevation and light-dismiss behavior.

```tsx
import { Popover } from '@cumulo/core';
```
