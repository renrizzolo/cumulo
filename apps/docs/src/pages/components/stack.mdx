# Stack

Flexbox layout primitive providing horizontal (`HStack`) and vertical (`VStack`) arrangement with token spacing and semantic HTML tag polymorphism (`as="section" | "nav" | "header" | "footer" | "ul" | ...`).

```tsx
import { Stack, HStack, VStack } from '@cumulo/core';
```

    </HStack>
