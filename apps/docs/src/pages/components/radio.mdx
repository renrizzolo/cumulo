# Radio & RadioGroup

An accessible, token-styled radio input component utilizing native `<input type="radio">` with circular indicator styling, error intent, and compound `RadioGroup` (`RadioGroup.Root`, `RadioGroup.Item`) grouping.

```tsx
import { RadioGroup, Radio, createRadioGroup, Field } from '@cumulo/core';

// Optional: create a strictly typed RadioGroup
const PlanRadioGroup = createRadioGroup<'standard' | 'pro' | 'enterprise'>();
```

## Orientation and custom layout

`RadioGroup.Root` renders a `Stack` container under the hood. It supports switching between `vertical` and `horizontal` orientations and accepts all flex props (`gap`, `wrap`, `justify`, `align`).
