# Radio & RadioList

An accessible, token-styled radio input component utilizing native `<input type="radio">` with circular indicator styling, error intent, and flex-powered `RadioList` grouping.

```tsx
import { Radio, RadioList, Field } from '@cumulo/core';
```

## Orientation & Custom Flex Layout

`RadioList` renders a `Flex` container under the hood, allowing easy switching between `vertical` and `horizontal` orientations and accepting all flex props (`gap`, `wrap`, `justify`, `align`).
