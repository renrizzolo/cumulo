# ButtonGroup

A segmented button toggle and action grouping component built on top of `Flex`. Supports single selection, keyboard arrow navigation, roving tab index, and full layout customization via flex props.

```tsx
import { ButtonGroup } from '@cumulo/core';
// or named imports
import { ButtonGroupRoot, ButtonGroupItem } from '@cumulo/core';
```

## Custom Flex Layout

Because `ButtonGroupRoot` renders `Flex`, you can pass standard layout props like `gap`, `wrap`, `justify`, and `align` to customize spacing and wrapping behavior.
