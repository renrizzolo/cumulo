# Menu

Accessible action menu built on native HTML5 `popover="auto"` and CSS Anchor Positioning, featuring full spatial arrow-key navigation (`ArrowDown`, `ArrowUp`, `Home`, `End`, `Escape`).

```tsx
import { Menu } from '@cumulo/core';
```
