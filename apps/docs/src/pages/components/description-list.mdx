# DescriptionList

DescriptionList provides semantic definition list primitives (`<dl>`, `<dt>`, `<dd>`) with support for icon markers, CSS grid or stacked layouts, proportional gap scaling (wider along the horizontal x-axis than the vertical y-axis), and custom term delimiters.

```tsx
import { DescriptionList } from '@cumulo/core';
```
