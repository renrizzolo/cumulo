# Checkbox

An accessible, token-styled form control that supports checked, unchecked, indeterminate, and error states.

```tsx
import { Checkbox } from '@cumulo/core';
```

## Field Integration

When used inside a `FieldRoot`, checkboxes automatically synchronize IDs, descriptions, accessibility attributes (`aria-invalid`), and error validation states.

  title="Form Field Integration"
  description="Checkboxes configured with valid and invalid Field contexts."
