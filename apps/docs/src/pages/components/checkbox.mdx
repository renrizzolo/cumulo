# Checkbox

An accessible, token-styled form control that supports checked, unchecked, and indeterminate states.

```tsx
import { Checkbox } from '@cumulo/core';
```

## Features

- **Indeterminate State**: Accessible `aria-checked="mixed"` with custom indicator.
- **T-Shirt Sizing**: `sm`, `md`, `lg`.
- **Field Integration**: Automatically registers with `Field.Root` for coordinated error states and labeling.
- **Form Compatible**: Uses visually hidden native checkbox for full form submission fidelity.
