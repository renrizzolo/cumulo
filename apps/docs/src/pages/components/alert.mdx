# Alert

Compound inline callout and status banner for communicating contextual feedback, warnings, errors, and system notices.

```tsx
import { Alert } from '@cumulo/core';
```

### Examples

## Variants and actions

Alerts support `secondary` (default), `outline`, and `primary` visual variants, plus an optional `Alert.Actions` slot for inline recovery buttons.

<ComponentPreview title="Variants & Inline Actions">
  <VStack gap="md" width="full">
    <Alert.Root variant="outline" intent="primary">
      <Alert.Icon />
      <Alert.Content>
        <Alert.Title>New SDK Version Available</Alert.Title>
        <Alert.Description>
          Upgrade to @cumulo/core 1.2 for native CSS anchor positioning support.
        </Alert.Description>
      </Alert.Content>
      <Alert.Actions>
        <Button size="xs" variant="secondary">
          Release Notes
        </Button>
      </Alert.Actions>
    </Alert.Root>

    <Alert.Root variant="primary" intent="error">
      <Alert.Icon />
      <Alert.Content>
        <Alert.Title>Revoked API Token</Alert.Title>
        <Alert.Description>
          The active service token was revoked by an administrator. Rotate credentials to restore access.
        </Alert.Description>
      </Alert.Content>
    </Alert.Root>

  </VStack>
</ComponentPreview>
